# 🤖 GREHANI – AI Agent

> An AI-powered conversational assistant built with HTML, CSS, JavaScript, Node.js, Express.js, and OpenRouter API.

## ✨ Features

- 🤖 AI-powered conversational assistant
- 💬 Interactive chat interface
- ⚡ Fast API-based communication
